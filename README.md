# Smart-Glove-Communication-for-Speech-disabled-Bedridden-people
Arduino-based smart glove that converts predefined finger-touch gestures into voice messages using Bluetooth and an Android application.

This project presents a wearable communication aid designed to help people who cannot communicate through speech. The glove uses touch/button sensors placed on the fingers to detect predefined gestures. An Arduino Uno processes the input and transmits the corresponding command through an HC-05 Bluetooth module. An Android application developed using MIT App Inventor receives the command and uses Text-to-Speech to convert the predefined message into spoken output.
